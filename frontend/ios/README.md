# BookSync Reader for iPhone

This Capacitor/Xcode project packages the same offline BookSync reader used by the web and Android targets. It imports a portable `.booksync.zip` generated by the processor, validates it locally, and keeps the book data in the device's private web storage.

## What is shared

- `../mobile/` provides the static PWA reader bundle.
- `../app/reader/` provides the reader, synchronization, package validation, and local library logic.
- `../capacitor.config.ts` defines the shared application identity and bundle source.

The mobile presentation uses a dark, music-first visual treatment designed for touch screens. It does not include Spotify branding, assets, or a copied proprietary interface.

## Build an IPA on macOS

An IPA must be signed using Xcode on macOS with an Apple Developer team. From `frontend/`:

```bash
npm run mobile:sync
npx cap open ios
```

In Xcode, set the Signing Team and a unique bundle identifier, then use **Product → Archive → Distribute App**.

For command-line development export after signing is configured:

```bash
xcodebuild -workspace ios/App/App.xcworkspace -scheme App -configuration Release -archivePath build/BookSync.xcarchive archive
xcodebuild -exportArchive -archivePath build/BookSync.xcarchive -exportOptionsPlist ios/ExportOptions.plist -exportPath build/ipa
```

The resulting IPA is `build/ipa/BookSync Reader.ipa`. Do not commit IPA files, signing certificates, provisioning profiles, or Xcode derived data.

## Build on GitHub Actions

The repository includes [`.github/workflows/ios-ipa.yml`](../../.github/workflows/ios-ipa.yml), which uses a GitHub-hosted macOS runner to build the IPA. Add these repository secrets before running **Build iPhone IPA** from the Actions tab:

- `IOS_CERTIFICATE_BASE64`: Base64-encoded Apple distribution or development `.p12` certificate.
- `IOS_CERTIFICATE_PASSWORD`: Password used when exporting the `.p12`.
- `IOS_PROVISION_PROFILE_BASE64`: Base64-encoded provisioning profile matching `com.mushfiq.booksync`.
- `APPLE_TEAM_ID`: Your ten-character Apple Developer Team ID.

Select `development` for registered test devices, `ad-hoc` for registered-device distribution, or `app-store` for TestFlight/App Store uploads. The signed IPA is retained as a private Actions artifact for 14 days.
